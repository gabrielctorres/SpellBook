# Referência da API

Aqui estão os tipos públicos do SpellBook, de runtime e de Editor, separados por namespace. Cada página mostra os membros de um tipo e o comentário XML escrito no código.

Para saber como usar um módulo, comece pelo [manual](https://gabrielctorres.github.io/SpellBook/). Para ver quais ações, reações e respostas o seletor do Inspector oferece, abra o [catálogo de tipos](https://gabrielctorres.github.io/SpellBook/referencia/catalogo/).
